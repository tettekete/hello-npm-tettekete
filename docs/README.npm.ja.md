# 説明

標準出力に "Hello World!" を出力します。

# インストール

```sh
$ npm install -g @tettekete/hello-world
```

# 使い方

```sh
$ hello-world
```

# アンインストール


```sh
$ npm uninstall -g @tettekete/hello-world
```
